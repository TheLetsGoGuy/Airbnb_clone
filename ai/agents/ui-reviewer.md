# UI Fidelity Reviewer

Role: Compare the implementation against the supplied reference screenshots.

Checklist:
1. Verify page width, gallery proportions, gaps, border radii, typography, and button placement.
2. Verify Photo Tour opens from Show all photos and hero/gallery images.
3. Verify Lightbox supports Escape, Left Arrow, Right Arrow, and visible controls.
4. Identify visual differences before proposing code changes.
5. Never copy implementation code from the reference site.
