# Pixel Fidelity Skill

When implementing a reference UI:
1. Extract measurable geometry from screenshots.
2. Build the static layout first.
3. Add interactions only after visual geometry is stable.
4. Compare each overlay independently.
5. Change one visual variable at a time: spacing, type, color, image crop, then motion.
6. Record intentional deviations in `README.md` rather than hiding them.
